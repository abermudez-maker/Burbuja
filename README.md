## Ejercicios

### Ejercicio 1: Burbuja con el arreglo 8, 5, 3, 1, 2

Ordena el arreglo `8, 5, 3, 1, 2` de forma **ascendente** con el método de la burbuja. Muestra paso a paso cada comparación y cada intercambio, como en el ejemplo de la presentación.

- **Resultado esperado:** `1, 2, 3, 5, 8`
- **Comparaciones:** 10
- **Intercambios:** 9

### Ejercicio 2: Burbuja con 1000 números aleatorios

Crea un arreglo de tamaño **1000**, lo rellena con números aleatorios entre 0 y 9999 y lo ordena con burbuja optimizada. La optimización detiene el proceso si en una pasada no hay intercambios. Imprime **ambos arreglos**: el original (desordenado) y el ordenado.
